01 / ABOUT

Building resilient DevOps infrastructure and high-performance backends.

I’m a 20-year-old DevOps and backend engineer born on July 16, 2006, based in Tehran, focused on infrastructure automation, reliable backend platforms, and production performance.

My core focus is DevOps and platform reliability — orchestrating automated CI/CD pipelines, Kubernetes, Ansible configuration management, zero-downtime blue-green deployments, Docker containerization, Linux server administration, and end-to-end observability stacks using Grafana, Loki, Alloy, and NGINX.

I actively leverage Large Language Models (LLMs) and AI-powered tools across my daily workflow to accelerate engineering, automate CI/CD code reviews, assist in debugging, and integrate smart API capabilities. From low-level frameworks like my zero-dependency TypeScript project Homa.js to multi-tenant distributed SaaS, I engineer systems built for reliability.
