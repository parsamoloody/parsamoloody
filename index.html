01 / ABOUT

I build backend systems that stay fast, clean, and scalable.

I’m a backend engineer based in Tehran, focused on performance, clean architecture, scalability, and production reliability.

I turn complex and legacy systems into modular services with clear boundaries. My work includes multi-tenant SaaS platforms, secure REST APIs, caching, encrypted data synchronization, database optimization, automated deployments, and monitoring.

I care about the full production lifecycle: designing maintainable code, preventing race conditions, testing services, deploying without downtime, and making failures visible. I also created Homa.js, a zero-dependency TypeScript web framework built directly on Node.js native HTTP modules.
